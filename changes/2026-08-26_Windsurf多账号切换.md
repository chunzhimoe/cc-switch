# 2026-08-26 Windsurf 多账号切换

## 背景 / 根因

希望把 cockpit-tools / WindsurfAPI 中的 Windsurf 切号能力接入 cc-switch：本机导入、Token/Auth1 添加、邮箱密码登录、写入 `state.vscdb`、关闭/重启 Windsurf。

## 修改文件与核心符号

### 后端

- `src-tauri/src/app_config.rs` — `AppType::Windsurf`
- `src-tauri/src/settings.rs` — `windsurf_app_path` / `windsurf_user_data_dir` / `current_provider_windsurf`
- `src-tauri/src/database/mod.rs` + `schema.rs` — `SCHEMA_VERSION = 17`，`migrate_v16_to_v17` 增加 `enabled_windsurf`
- `src-tauri/src/windsurf/` — `account` / `paths` / `local_import` / `auth_write` / `inject` / `process` / `devin_oauth`
- `src-tauri/src/commands/windsurf.rs` — list/import/addToken/addPassword/delete/switch/status
- `src-tauri/src/mcp/windsurf.rs` + MCP/provider/skill/config 分发接入
- `src-tauri/Cargo.toml` — `sysinfo`、Windows `aes-gcm` / DPAPI `windows` features

### 前端

- `src/lib/api/windsurf.ts` / `src/hooks/useWindsurf.ts`
- `src/components/windsurf/WindsurfAccountsPanel.tsx`
- `src/App.tsx` / `appConfig` / AppSwitcher / 可见性与 MCP 面板接入
- i18n：`zh` / `zh-TW` / `en` / `ja`

## 行为差异

### 之前

- cc-switch 无 Windsurf 应用类型与账号面板。

### 之后

- 可启用 Windsurf 应用入口。
- 支持导入本机登录态、添加 `sk-ws-*` / `cog_*` / `auth1_*` / `devin-session-token$*`。
- 支持 Devin Auth1 邮箱密码登录（`login_with_password` → `full_refresh_from_auth1`）。
- 切换账号时：检测 EXE → 关闭进程 → 注入 `state.vscdb` → 重启。
- MCP 统一管理增加 Windsurf 开关（schema v17）。
- SecretStorage 写入当前阶段仅完整支持 Windows。

## 测试

- 本机无 `cargo`，未执行 `cargo check` / `cargo test`。
- 已静态核对：`mod windsurf`、命令注册、`ProviderService` live inject、前端 API/面板/i18n。
- 剩余风险：需依赖 CI / 有 Rust 环境的机器做编译与真机切号验证。
