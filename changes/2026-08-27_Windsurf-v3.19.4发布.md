# Windsurf v3.19.4 发布

## 发布背景

在 `release/windsurf-v3.19.4` 分支上发布包含 Windsurf 多账号、Auth1 登录、浏览器 OAuth、静默切号以及相关分类器兼容修复的版本。此次发布同步将应用、Tauri 和 Cargo 的稳定版本号统一为 `3.19.4`。

## 版本变更

- `package.json`：版本更新为 `3.19.4`。
- `src-tauri/Cargo.toml`：crate 版本更新为 `3.19.4`。
- `src-tauri/Cargo.lock`：`cc-switch` package 版本更新为 `3.19.4`。
- `src-tauri/tauri.conf.json`：Tauri 应用版本更新为 `3.19.4`。

## 本版本包含的 Windsurf 能力

- Windsurf 多账号持久化与账号切换。
- Token/Auth1、邮箱密码登录。
- 浏览器 OAuth wait-callback 登录及手动粘贴回调 URL 兜底。
- Windows 切号时静默结束进程，复用同一 `user-data-dir` 和 `--reuse-window`，由 Windsurf 自然恢复上次页面/工作区。

## 相关稳定性修复

- 修复 Claude Code Auto 分类器在外部 `ANTHROPIC_BASE_URL` 直连时无法生效的问题：将模型投影到 `CLAUDE_CODE_AUTO_MODE_MODEL`，不要求本地代理接管。
- 修复本地代理对 billing header 与安全分类器 marker 合并文本的漏判。
- 增加分类器诊断日志，并限制日志只包含安全元数据。
- 根据 CI 反馈补齐 Rust dead-code 与 rustfmt 修复，避免 `-D warnings` 阻断构建。

## 验证

- 本地 TypeScript、定向 Vitest、Prettier、Renderer 构建、locale JSON 和 `git diff --check` 已通过。
- 本机没有 Cargo/Rust 工具链，Rust 编译、测试和跨平台打包由 GitHub Actions Release workflow 执行。
- 版本元数据四处均已校验为 `3.19.4`。

## 已知事项

- Release workflow 由推送 `v*` 标签触发，并发布为 prerelease。
- 当前只发布 `v3.19.4-windsurf.1`，不覆盖已有标签。
- `pnpm-workspace.yaml`、`.waylog/`、`@plan/`、`WindsurfAPI/`、`cockpit-tools/` 等无关本地改动不纳入提交。
