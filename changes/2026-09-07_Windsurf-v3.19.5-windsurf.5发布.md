# 2026-09-07 Windsurf v3.19.5-windsurf.5 发布

## 背景

在 macOS Devin/Windsurf 邮箱密码账号切换修复完成、本地前端验证通过且 release 分支 CI 全绿后，发布 `v3.19.5-windsurf.5` 公共预发布版本。

- 分支：`release/windsurf-v3.19.4`
- 标签：`v3.19.5-windsurf.5`
- 标签目标：`e5304786980ab5b2967d0676dcc951fe2605163a`

## 包含修复

- 区分 PostAuth session 与 IDE credential，避免把 IDE token 当作客户端 session 注入。
- 切号关闭/写入前刷新 Auth1，刷新失败时不关闭客户端、不写 live、不修改 current。
- macOS 仅查询目标应用精确的 `${nameLong} Key`，不跨 Devin/Windsurf 品牌回退。
- 清除 `windsurf.pendingApiKeyMigration`，避免客户端启动后用旧迁移值覆盖 sessions。
- 写入后解密比较 SecretStorage sessions 与 apiServerUrl，不再把 `v10` 前缀视为成功证明。
- 成功提示仅声明会话写入已校验和客户端已启动，不声称客户端已经在线登录。
