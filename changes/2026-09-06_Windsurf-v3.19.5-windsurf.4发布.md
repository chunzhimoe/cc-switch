# Windsurf v3.19.5-windsurf.4 发布

## 发布背景

在 `release/windsurf-v3.19.4` 上发布供应商级 Auto 分类器跳过配置的增量版本。应用、Tauri crate、Cargo lock root 与 Tauri 配置版本仍统一为 `3.19.5`；本次使用递增预发布标签，不覆盖已有 `.1`、`.2`、`.3`。

## 本版本变更

- 当 Claude 供应商显式启用 `meta.skipAutoClassifier` 时，live settings 现在同时投影：
  - `permissions.defaultMode = "bypassPermissions"`
  - `sandbox.enabled = true`
  - `skipDangerousModePermissionPrompt = true`
- 直连、代理热切和代理备份均复用同一有效配置构建入口。
- 切走、关闭开关与通用配置同步会对称恢复供应商/共同片段原值，避免 live-only 注入固化到数据库或污染其他供应商。
- 四语言界面描述和 destructive confirmation 明确披露新增参数及危险模式确认被跳过的效果。
- 完整实现、调用链和风险记录见 [2026-09-06 跳过危险模式确认提示](./2026-09-06_跳过危险模式确认提示.md)。

- 本次 fork Release 没有 `.sig` 文件，生成的 `latest.json.platforms` 为空。因此手动下载安装可用，但不能通过 Tauri 应用内 updater 自动更新；也不能声称这些包具有官方签名/公证。
- 该功能是用户在供应商表单中显式确认开启的高风险选项；默认关闭，不会修改未启用供应商。
- 若 Claude Code 后续改变 `skipDangerousModePermissionPrompt` 的键名或读取时机，需要同步更新投影、恢复和文案。
