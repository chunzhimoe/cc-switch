# 供应商级跳过 Auto 分类器

## 目标

在每个 Claude 供应商的“编辑供应商 → 高级选项”中增加高风险开关。启用后，CC Switch 在生成该供应商的 Claude live settings 时注入：

```json
{
  "permissions": { "defaultMode": "bypassPermissions" },
  "sandbox": { "enabled": true }
}
```

该方案通过 Claude Code 的权限配置避开 Auto 分类器，适用于外部 URL 直连和本地代理；不在代理层伪造分类器响应。

## 实施范围

1. `ProviderMeta` 新增可选字段 `skipAutoClassifier`，旧数据默认关闭。
2. Claude live 配置应用/回填时对上述两个叶子字段做对称投影，保留兄弟字段和用户手工修改。
3. 开关启用时暂停 `CLAUDE_CODE_AUTO_MODE_MODEL` 的派生投影，但保留已有分类器分流配置，关闭后恢复。
4. 前端增加 destructive 二次确认、持续风险提示、重启提示和分流暂停提示。
5. 覆盖四种语言文案、Rust 投影测试和前端交互测试。

## 验收标准

- 每个 Claude 供应商可独立启用/关闭；其他应用供应商不显示。
- 切换供应商时不会把注入字段固化到 `settingsConfig`，也不会污染下一供应商。
- 原有 `permissions.allow/deny`、sandbox 其他键和分类器模型列表不丢失。
- 启用后 live 配置为 `bypassPermissions + sandbox`，且不再注入 Auto 分类器模型。
- 前端测试、类型检查、Renderer 构建和可执行的 Rust 测试通过。
